## 已落地

- 迁移脚本 `docs/sql/cnpa-website-update-r4-theme.sql` 已写入仓库。新建 `basket_site_theme` 和 `basket_site_theme_binding`。没有写入示例配色。脚本可重复执行。
- 这条 SQL 没有在任何库执行。前三轮脚本同样没有执行。
- 主题包含名称、说明、背景色、背景图、手机背景、展示方式（顶部居中、滚动、固定）、十个语义色和乐观锁。已发布主题再保存，只写草稿 JSON。复制会新建一行，草稿是一份新的 JSON，不和原主题共用。
- 绑定范围是 `HOME`、`BASE`、`SEASON`。赛季绑定使用 `basket_season.id`。发布前可以查看将影响的首页、基础主题或赛季；如果该位置已经绑了别的主题，会提示将被替换。
- 恢复默认只解除绑定，主题行还在。停用或删除正在使用的主题后，公开接口不再返回它，页面回到基础主题；基础主题也没有时，回到现在这套默认颜色。
- 公开接口 `GET /basket/public/theme?scope=&seasonId=` 只返回已发布主题。解析顺序：首页用首页绑定，没有则基础主题；路由上有赛季 ID 时用该季绑定，没有则基础主题；数据中心、名人堂、公告、合作伙伴只请求基础主题。`/account/**` 不请求主题。
- 官网在主题结果写上 CSS 变量之后才显示公开页主体，避免先画出默认红再跳色。图片打不开时仍使用这套颜色，背景图去掉。请求失败时用默认颜色，页面数据照常渲染。
- 第一批接入变量的是页面背景层、首页主要按钮、首页筛选和赛区筛选、数据中心与公告和名人堂的分页、标题英文装饰、数据表表头、合作伙伴表头。球队 Logo、成功、警告、错误色和图表颜色没有改。
- 后台「站点主题」挂在内容运营下面，菜单号 2374。悬停、按下、焦点、禁用在编辑框里由主色生成预览，不单独入库。草稿预览只在后台，没有对未登录用户开放。
