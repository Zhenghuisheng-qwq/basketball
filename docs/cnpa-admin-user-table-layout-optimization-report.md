# CNPA 后台用户管理列表布局优化报告

> 生成时间：2026-08-01  
> 定位：仅前端列表展示结构优化；不改业务逻辑、接口、数据库、查询与分页

---

## 1. 修改目标

将「账号与认证 → 用户管理」列表第一列「用户信息」中堆叠的头像 / 昵称 / 邮箱 / 用户ID，拆成三列独立展示，降低行高与视觉拥挤，便于快速扫数据。

---

## 2. 修改页面文件

| 文件 | 变更 |
|------|------|
| `basketball-admin-ui/src/views/cnpa/identity/account-player/index.vue` | 表格列拆分、列宽与 ellipsis/tooltip、行内样式微调 |

未修改任何后端、接口、Mapper、VO、查询条件或分页逻辑。

## 4. 是否只做了展示优化

**是。** 仅调整 `el-table-column` 结构、slot 模板、列宽与局部 CSS（用户信息单元格改为水平头像+昵称；单元格垂直对齐改为 middle）。

---

## 5. 是否改动了后端

**否。** 直接复用列表接口已有字段：`avatarUrl`、`nickname`、`email`、`userId` / `memberId`。

1. 用户ID 列可提供「一键复制」

4. 列显示开关（right-toolbar 列配置）可按运营习惯隐藏用户ID
